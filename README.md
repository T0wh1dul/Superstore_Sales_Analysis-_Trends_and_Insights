# Superstore_Sales_Analysis-_Trends_and_Insights
Excited to share my latest data analysis project! 🎉

I dove into the Superstore Sales dataset to practice my Exploratory Data Analysis (EDA) skills. My goal was to clean up the data and then explore it to find interesting patterns and answer some key business questions, like:

**How do sales change over time? 📈

**Which product categories bring in the most revenue? 💻🛋️📎

**How do sales differ across various customer segments? 👥

It was fascinating to discover clear seasonal sales peaks (especially near year-end!) and see how important the Technology and Furniture categories are. The Consumer segment also stood out as the biggest contributor to sales.

For this project, I used Python along with libraries like Pandas for data wrangling, and Matplotlib/Seaborn for creating visualizations.
